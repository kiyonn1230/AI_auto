# 社名・ブランド案

## 採用案：株式会社ツムギAI（Tsumugi AI Inc.）

| 項目 | 内容 |
| --- | --- |
| 社名 | 株式会社ツムギAI |
| 英語表記 | Tsumugi AI Inc. |
| タグライン | 業務を、AIで紡ぎなおす。 |
| 由来 | 「紡ぐ（つむぐ）」＝バラバラの糸を1本の強い糸にすること。分断された業務・ツール・データをAIでつなぎ、ひとつの流れに仕立て直す、という意味を込めています。 |
| トーン | 誠実・親しみやすい・日本の中小企業に寄り添う |
| ドメイン候補 | tsumugi-ai.jp / tsumugi-ai.co.jp / tsumugiai.com |

### 選定理由
1. **意味が事業と一致**：「業務フローをつなぐ＝自動化」というサービスの本質を1語で表せる。
2. **覚えやすい**：ひらがな3音＋AI。電話口でも伝わりやすい。
3. **日本らしさ**：海外SaaSとの差別化になり、中小企業の経営層にも親しみやすい。
