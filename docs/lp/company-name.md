# 屋号の検討メモ

## 決定：テマカル

| 項目 | 内容 |
| --- | --- |
| 屋号 | テマカル |
| ローマ字表記 | Temakaru |
| 事業形態 | 個人事業。税務署への開業届で、屋号として届け出る |
| 由来 | 「手間を軽く」。毎月くり返す面倒な業務をAIで軽くする、という事業の説明をそのまま名前にした |
| タグライン | くり返す手間を、AIで軽くする。 |
| ドメイン候補 | temakaru.jp / temakaru.com（2026-09-29 時点で DNS 上の登録は見つからず。取得時に改めて確認） |
| サービス名の付け方 | 屋号＋中身が分かる名前（例：テマカル 保護者レポート、テマカル 予約管理） |

### 選んだ理由

1. **意味がすぐ伝わる**：教室やサロンのオーナーが聞いて、何をしてくれるところか想像がつく。
2. **電話で言いやすい**：4文字で、聞き間違えにくい。
3. **造語なので、既存の事業とぶつかりにくい**：意味の良い普通の言葉は、AI・業務効率化の分野ではほぼ使われていた（下の表）。

屋号には「AI」を入れていない。「〇〇AI」という名前はすでに大量にあって埋もれやすく、
お客さんが知りたいのは「AIかどうか」より「何が楽になるか」なので。
